# necosystem
A simple ecosystem simulation game powered by Unity.
Watch an ecosystem in motion on a small, remote island.

## Codebase features
- Perlin noise terrain generation.
- Animal pathfinding using the A* algorithm.
- OOP for animal classification and private methods between the different roles in the food chain.

## Game features
- WASD controls and scroll wheel to move across the island.
- Clicking on an animal allows viewing of its live statistics like hunger and age.
- Press F on a selected animal to favourite it, keeping it highlighted in gold.
- Use the hotbar to spawn more foxes or rabbits, and watch how it affects the ecosystem.

_Disclaimer of a known bug that the animal AI breaks after a few minutes of gameplay!_
